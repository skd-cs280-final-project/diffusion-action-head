# 成员 A 单步动作头与条件注入

[团队总览](README.md) · [实验协议](../experiments/protocol.md)

## 固定条件

H=1、E=1、无数值历史、骨干与原 adapter 冻结，动作维度与 LAND 标签保持原定义。扩散版本固定 DDPM、100 个训练噪声步、10 步推理去噪。

## 实验

| 编号 | 方法 | 条件 | 比较目的 |
| --- | --- | --- | --- |
| A0 | 当前 Transformer 扩散头 | 完整 token cross-attention | 训练共同基准，复用现有实现 |
| A1 | 确定性 Transformer 回归 | 完整 token cross-attention | 与 A0 比较生成方式 |
| A2 | MLP 扩散头 | 池化条件调制 | 简单扩散网络 |
| A3 | Transformer 扩散头 | 池化条件调制 | 与 A0 比较条件注入，与 A2 比较整体结构 |

A1 使用可学习动作查询直接预测归一化动作；与 A0 保持尽可能接近的条件投影、层数、宽度和容量。A2/A3 的池化必须屏蔽文本 padding；调制具体方式在开发阶段选定并记录。A0/A3 除条件路径外尽量固定主体。报告参数量、耗时，不能将不同容量的差异全部解释为结构优势。

## 实现边界

在 `src/course_heads/` 新增模块，在 `scripts/course_train/a/` 新增训练入口。原 `src/model_wrapper/diffusion_action_head.py` 作为参考路径保留。A 负责跨模型加载注册和 schema 扩展，但不修改 B 的数据集和仿真执行代码。

训练 loss 可以不同，不能用不同任务的训练 loss 横向评价性能。主表比较同预算最终权重；离线使用共享动作指标。直接回归无 noise MSE，将该字段留空或 null，而不是填 0。

## 完成标准

- A0 复现，明确实际数据、预算和权重路径。
- A1–A3 能训练、保存、独立重载和预测四维归一化动作。
- 冻结参数无梯度、padding 正确、checkpoint 往返一致、旧格式加载不回归。
- 每个正式检查点附运行清单和离线指标，交 C 做闭环。
- 撰写动作扩散原理、网络和条件注入章节，解释正负结果及计算代价。
