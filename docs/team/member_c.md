# 成员 C 多候选动作选择与运行成本

[团队总览](README.md) · [实验协议](../experiments/protocol.md)

使用已有扩散模型，研究不更新参数的候选选择策略。N 是独立动作候选数量，每个候选始终完成固定 10 步 DDPM；N 不是扩散步数。

## 三类实验

| 编号 | 内容 | 控制 |
| --- | --- | --- |
| C1 | N=1 原策略；N=4/8 的移动动作 medoid | 从实际候选中选代表，不用测试标签或执行后的结果挑选 |
| C2 | 固定 N=4，LAND 投票后在继续飞行候选中选 medoid | 与同 N 的 C1 比较；平票与无候选规则预先固定 |
| C3 | 质量/成本关系，分解骨干、采样、选择、完整决策延迟 | 固定硬件/精度/线程，预热和 CUDA 同步，记录平均/P95/显存/任务耗时 |

C1 的 medoid 距离在归一化前三维计算，选择该候选的完整四维动作；C2 明确 LAND >=0 的二元投票规则，平票沿用预先指定候选的停止判断，不根据测试结果临时改规则。继续飞行时只在 land<0 的候选中选移动动作。不能假设动作平均或 medoid 一定更好。

## 实现与公共工作

`evaluation/course/selection/` 只负责选择和计时；使用 A 的候选采样接口，同观测缓存一次条件。不能跨不同权重/输入缓存条件，也不能借助 GT、未来状态或 oracle 评分排序。`scripts/course_infer/c/` 提供独立入口。

负责最小指标 JSON/CSV 和配对统计合同，提供轻量公共函数；A/B 各自运行并作图，C 不代跑全队闭环。原 AeroVLA 的 N 候选策略不在本实验中人为复制；它仅作标准单次策略和计时参考。

## 均分工作与完成标准

完成自己负责的 9 个 S0 模型及 S1 约 1/3 任务，自行执行 C1/C2 的正式闭环。候选开销较大，先按实测成本限定正式条件数，不能把额外仿真工作全部交别人。

验证 N=1 与原预测一致、固定候选能重现选择、平票/全 LAND/全部继续等边界正确，权重未改变。建议图：SR/目标距离与耗时关系、分段耗时、LAND 决策变化；补一个多候选改善和一个退化案例。撰写推理策略与计算成本章节。
