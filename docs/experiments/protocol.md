# 课程实验协议 v1

[团队分工](../team/README.md) · [机器可读协议](../../configs/course/protocol.json)

本协议定义待开展的课程实验。历史实验只能作为来源说明，不能填入新实验结果。配置清单的 `planned` 表示待实现或待运行，不是启动成功。

## 固定条件

| 项目 | 固定值 / 约定 |
| --- | --- |
| 条件 | 当前前视/下视 RGB 和当前导航指令 |
| 骨干 | 相同 OpenVLA 和原 AeroVLA adapter，全部冻结 |
| 数值历史 | history_length=0 |
| 动作 | fwd/down/yaw/land，原裁剪范围与 LAND 标签 |
| 扩散算法 | DDPM |
| 训练噪声步数 | 100 |
| 推理去噪步数 | 10 |
| 基准头 | hidden=256、layers=4、heads=8、dropout=0 |
| 默认训练预算 | 全 train，5 epochs，batch 2 × accumulation 8，单 GPU |
| 优化 | 学习率 1e-4，weight decay 0.01，warmup ratio 0.03，梯度裁剪 1.0 |
| 训练种子 | 42 探索，关键对照补 43、44 |
| 离线评估 | val 全集，batch 2，seed 42 |
| 在线评估 | 初次 seed 100；重复采样另记，不等于独立训练 |
| 主检查点 | 相同预算最终权重，记录实际更新数与样本暴露量 |

不安排扩散步数、DDPM/DDIM、历史、联合 LoRA、安全层或停止解耦实验。H/E 是动作预测和执行长度，不是去噪步数。确定性模型不运行扩散过程，采样配置记为不适用。

这些是可复现的课程初始预算，不是声称已完成 5 轮训练。开发阶段可以统一缩减样本和预算；正式变更需同步所有对照并记录协议版本。H 不同的样本起点保持一致，loss 按有效坐标归一化；报告有效监督动作数，不能假设每个起点的信息量完全相同。

## 数据与调参隔离

当前默认 train 369,274 帧 / 6,850 条轨迹，val 41,176 帧 / 761 条轨迹。split 按轨迹隔离，帧抽样在校验后进行；同地图轨迹留出不等于未见地图。

C 在开发前冻结闭环开发任务和最终任务 UUID，分层考虑地图和参考轨迹长度，不能取排序最前 N 条。若开发任务来自官方 NYC 281 条，正式报告同时列出未用于开发的部分；全 281 条只能作为官方集合汇总，不能称完全未见测试。历史上已反复查看的任务应披露使用情况。未见地图任务也要核对原 adapter 来源；无法核实其预训练重叠时，不声称整个系统完全无泄漏。

LAND 阈值固定沿用原归一化 >=0；不在正式集合选择模型或阈值。输入中的目标方向提示和执行/终止协议保持一致。

## 指标

- 共同第一步：归一化连续动作 MSE、逐维 MAE/RMSE、LAND 混淆矩阵和 P/R/F1。
- 多步：按预测位置和有效样本数分别汇总，不能直接用不同 H 的整体均值替代共同第一步。
- 扩散 noise MSE：仅作该类模型内部诊断；直接回归记 null，不以 0 冒充最佳。
- 闭环：SR、OSR、原协议 SPL、目标距离、参考终点距离、总分母与未完成数。
- 成本：参数量、显存、骨干/头/完整决策的平均与 P95 延迟，调用次数、动作数和任务墙钟时间。
- 失败：物理接触、深度近障、停滞、过早停止、未停止和超时分别记录，保留真正触发退出的原因。

原 `utils/metric.py` 的 NE 是参考终点距离，SPL 以参考轨迹长度减 20 计算，不应写成标准最短路径 SPL。失败提前终止会减少动作数，不能用总体平均动作数下降宣称效率提高。

## 统计和完成标准

同任务 UUID 配对，列出新增成功和新增失败。置信区间以任务/轨迹为单位，重复采样保持分组；不能将帧或同任务重复运行当作独立任务。关键对比做独立训练种子，推理随机种子另列。

正式运行前检查：配置固定、权重可独立重载、数据 provenance、最小闭环通过、UUID 唯一、原始日志保留。中断任务不计为普通失败，不保留同任务的半条轨迹参加指标；续跑记录重新设种子与 RNG 未恢复的事实。C 根据完整清单决定何时可标记 completed。

结果由[运行模板](../../evaluation/course/run_manifest.example.json)登记；A/B 完成方法说明与离线分析，C 负责正式配对与主图表。
