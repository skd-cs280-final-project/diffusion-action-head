# 课程推理实验协议 v2

[团队分工](../team/README.md) · [配置](../../configs/course/protocol.json) · [完整模型清单](../../configs/course/models.json)

本版本替代旧 A0–B4 训练型方案。使用现有正式权重，不训练、不更新参数、不新增动作头或多步预测。代码/规范准备不等于实验完成，全部新增运行状态仍为 not_run。

## 固定设置

| 项目 | 约定 |
| --- | --- |
| 权重 | models.json 登记的现有模型；不做梯度更新 |
| 扩散 | DDPM，原训练日程 100，每次推理完整 10 步 |
| H/E | 1/1，不增加多步预测或动作重复执行 |
| 历史 | 0，保留原双视角与当前导航提示 |
| 骨干 | 每个 checkpoint 使用它自己的原模型/adapter/联合权重；全部 eval/no_grad |
| 动作 | 原 fwd/down/yaw 定义与裁剪；扩散 LAND >=0，token 保留原文本/零动作停止解析 |
| 离线 | 同一 val，batch=2；主 seed42，重复推理 seed42/43/44 |
| 闭环 | 主 seed100，重复推理 seed100/101/102；episode 级种子派生规则统一 |
| 控制与判据 | 原执行器、成功判据和环境终止规则不变 |

联合权重的骨干已适配，不能强制只加载扩散头而漏掉 joint_adapter.pt。确定性参考模型的 noise MSE/扩散过程记为不适用。重复推理不等于独立训练；联合中间权重是同一优化轨迹上的检查点。

## 任务分片与工作量

B 在观察方法结果前按长度/地图分层，固定开发和最终 UUID；最终 S1 按任务分为三份，三人对各自分片跑全部代表模型。每个模型的完整结果通过三份合并，核对唯一 UUID/总数。不同组不能各跑不同模型再混淆硬件或任务差异。

用试跑的 GPU 小时、仿真小时、wall time 和实际开发工作重新均衡；C 多候选成本高时可减少正式策略组合，A/B 在本线补对应分析，不增加新的训练任务。对自己正式变体负责到底，公共统计代码不等于 C 代跑、代画、代写。

## 数据与统计

沿用轨迹隔离 val，但不得称整个预训练系统完全未见；原 adapter 训练重叠仍需披露。闭环开发/最终集合预先固定；历史上查看过的任务不能仅因改名就称全新测试。方向提示的目标信息条件在各模型中保持一致。

共同指标为第一步连续动作 MSE、逐轴 MAE/RMSE、LAND 混淆矩阵/P/R/F1/正例数；扩散 noise MSE 只作类内诊断，原 token 策略记 null。原策略解析失败单独计数，不能默默丢弃后只报告成功解析样本。

闭环报告 SR、OSR、原协议 SPL、目标距离、参考终点距离、请求数/完成数。物理接触、深度近障、停滞、早停、未停止、超时分别记录，原判据不变。原 NE 实为参考终点距离，SPL 的参考路径长度减 20，保持命名清楚。

按 UUID 配对，以任务为统计单位；推理种子重复嵌套于任务，不把帧/重复采样当独立任务。相同 seed 不保证不同方法消费同样随机数；使用独立噪声和输入扰动 RNG，并保存实际规则。噪声变化反映推理稳定性，不代替训练方差。

B 的遮蔽产生分布变化，只解释当前策略依赖；A 的分布方差不是风险校准；C 不能使用 GT 或未来执行成绩选候选。所有策略参数在开发集冻结，最终集合只评估一次定义好的方案。

## 运行成本与复用

同一模型、相同原始输入与预处理才能复用条件特征。采样 N 个候选时可缓存一次 VLM 条件，不跨权重或扰动缓存。推理过程预热并 CUDA 同步，分别报告骨干/头/选择/端到端的平均/P95；记录随机 seed、N、精度、线程、设备和 batch。

阶段权重训练预算不同，头 best 与联合 final 的比较是已有阶段模型对照，不是等预算重新训练消融。失败早停使总动作数变少，不能据此宣称更高效。
