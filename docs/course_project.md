# 课题简介与报告提纲

**题目：《基于预训练扩散动作头的无人机视觉语言导航推理评测与分析》**

本课题以现有 AeroVLA 系统为基础，研究已经训练好的扩散动作头在无人机视觉语言导航中的推理表现。通过现有离线动作评估与 AirSim 闭环入口，比较原 AeroVLA、只训练动作头、联合初始化、中间联合检查点和联合最终模型，并分析已见场景、未见目标和未见场景中的性能差异。

工作以复现、系统评测和结果分析为主，不提出新网络或新采样算法，不重新训练，不修改代码与框架，不比较扩散步数。已有模型的训练过程仅作为方法来源介绍，不能写成本课程新完成的训练贡献。

## 研究问题

1. 相同任务和执行设置下，原策略与扩散动作头模型的 SR、OSR、SPL、NE 有何差异？
2. 仅头训练、联合初始化、中间检查点与 final 的表现如何变化？离线误差与闭环成功率是否一致？
3. 已见场景、未见目标、未见场景，以及 easy/hard 轨迹下，哪些现有模型表现更稳定，失败模式有何差异？

## 数据和模型范围

26 个扩散状态全量离线；五个代表模型闭环覆盖现有 20 组场景/划分、12 个场景、3,005 个任务，总计 15,025 次正式模型-任务运行。三人各有 15 次额外推理预检，预检不计正式结果。所有新结果仍待执行；现有历史报告仅是背景证据。

任务按三人近似等量分配，明确到场景、JSON、模型、参数和命令，见[详细分工](team/README.md)。ModularPark 分片已固定；不按模型表现选择或排除任务。

## 报告建议结构

1. 引言：视觉语言导航任务、使用扩散动作头的动机与本课题目标。
2. 方法背景：现有图文条件、动作四维定义、扩散去噪与单步执行；已有训练阶段及冻结/联合范围。
3. 评测设置：模型清单、数据划分、20 组场景、固定参数、三人分工、原指标口径。
4. 离线结果：全 26 状态的动作与 LAND 指标，联合检查点变化；不能把同次训练的 checkpoint 当独立重复。
5. 闭环结果：五模型总表、按场景/划分和 easy/hard 分组的表格与图。
6. 案例分析：同任务五模型对照，成功、过早停止、未到达等在已有输出可支持范围内的失败描述。
7. 局限与结论：训练预算不同、原 adapter 数据重叠、历史任务使用、全局随机数与续跑、缺失/中断说明。

每人写自己的场景结果、案例和运行记录，公共方法与总表共同核对。评价依据是完整、可追溯的推理结果，不把尚未运行的计划数字写成实验完成数量。
